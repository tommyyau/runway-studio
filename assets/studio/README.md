# Studio UI illustrations

These images are rendered from Runway Studio’s actual SwiftUI views with deterministic synthetic data. They contain no personal account usage, credentials, private project names or imported history. The dropdown uses a taller viewport to show its scrollable content; display options are set for the illustrated layout.

Regenerate on macOS with `bash script/render_studio_docs.sh`. The development-only renderer uses an isolated temporary store, suppresses notifications and provider monitoring, and removes its temporary state after export. These assets describe Studio; the older images elsewhere in `assets/` are retained upstream references.
